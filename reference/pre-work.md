# Pre-work — 30 minutes, before the lab day

Arrive with all four of these done. Anything not done here comes out of lab time.

---

## 1. Install Claude and sign in

**Desktop app (recommended):** download from [claude.ai/download](https://claude.ai/download),
install, sign in with your Claude account (Pro or Max).

**Terminal, if you prefer:** `npm install -g @anthropic-ai/claude-code` then `claude`.

Do **not** use the claude.ai web chat for the labs — it cannot read and write
files in a folder, which is the entire point of the day.

---

## 2. Prove it can touch a file

Open the app, open any folder, and type:

```
create a file called hello.md containing the line: I am ready for the workshop
```

Click **Allow** when it asks permission. If `hello.md` appears on disk, you're
set. If it doesn't, say so in the group chat **before** the lab day — don't
arrive stuck.

---

## 3. Put this folder on your desktop

Unzip `fernway-triage` and leave it on your desktop. Don't rename it — the labs
refer to it by name.

---

## 4. Set up a Gmail app password  ← the one that takes longest

Lab 5 ends with your agent sending a real email. It needs a Gmail account it is
allowed to send from, which means an **app password**.

**Use a personal Gmail account, not your institute account.** Managed accounts
usually have app passwords switched off by the administrator, and you cannot
turn them back on yourself.

1. Sign in to your personal Google account
2. Turn on **2-Step Verification** — [myaccount.google.com/security](https://myaccount.google.com/security).
   Google will not issue an app password without it.
3. Go to [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
4. Create one, name it `fernway-workshop`
5. Copy the 16-character key and keep it somewhere you can find on the day

That key is **not** your Gmail password. It works for one app, it does nothing
else, and you can revoke it in one click when the workshop is over.

> **If the app password page refuses you**, your account is managed. Create a
> free personal Gmail account and do it there. Ten minutes now; a dead lab if
> you leave it to the day.
